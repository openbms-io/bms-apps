I want TypeScript types and API client generated from the Control Sequence API OpenAPI spec,

5. Client configured with correct baseUrl for nginx proxy route (`/control-sequence`)

### Existing Pattern Reference

**building-semantics package.json script:**

```json
"generate:api-client": "openapi-ts --input http://localhost:8000/openapi.json --output ./src/domains/building-semantics/api/generated --client @hey-api/client-fetch && sed -i '' \"s|baseUrl: 'http://localhost:8000'|baseUrl: '/building-semantics'|g\" ./src/domains/building-semantics/api/generated/client.gen.ts"
```

**building-semantics/api/config.ts:**

```typescript
import { client } from "./generated/client.gen";

export const API_BASE_URL =
  process.env.NEXT_PUBLIC_SEMANTICS_API_URL || "http://localhost:8000";

client.setConfig({
  baseUrl: API_BASE_URL,
});
```

### Expected Generated Types

Based on Control Sequence API DTOs (from Story 1.15, 1.16):

```typescript
// Parameters DTO
interface ReheatParameters {
  VCooMax_flow?: number;
  VHeaMax_flow?: number;
  VMin_flow?: number;
  // ... with JSDoc from Field descriptions
}

// Inputs DTO
interface ReheatInputsRequest {
  zoneTemperature: number; // ge=15.0, le=40.0
  coolingSetpoint: number; // ge=18.0, le=30.0
  heatingSetpoint: number; // ge=15.0, le=25.0
  dischargeAirTemperature: number;
  dischargeAirflow: number;
  supplyAirTemperature: number;
  supplyAirTemperatureSetpoint: number;
  supplyFanStatus: boolean;
  operationMode: number; // ge=1, le=7
}

// Outputs DTO
interface ReheatOutputs {
  damperPosition: number; // 0.0-1.0
  valvePosition: number; // 0.0-1.0
  airflowSetpoint: number; // m³/s
}

// Request/Response DTOs
interface StepRequest {
  stepSize: number;
  inputs: ReheatInputsRequest;
}

interface StepResponse {
  instanceId: string;
  outputs: ReheatOutputs;
}
```
