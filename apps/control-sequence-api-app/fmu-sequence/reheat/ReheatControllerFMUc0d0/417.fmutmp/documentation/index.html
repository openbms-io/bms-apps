ReheatControllerFMU

FMU wrapper for G36 VAV Reheat Terminal Unit Controller with all parameters tunable

Information

FMU export wrapper for the ASHRAE Guideline 36 VAV Reheat Terminal Unit Controller.

This model extends the base Controller with all parameters exposed as tunable FMU parameters. Each parameter is declared explicitly and passed through to the base controller, ensuring they appear as configurable parameters in the FMU.

For parameter documentation, see: Buildings.Controls.OBC.ASHRAE.G36.TerminalUnits.Reheat.Controller
